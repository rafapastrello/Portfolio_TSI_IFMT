Sobre a Disciplina

Fundamentos da Computação é a disciplina que revela o que há por trás de qualquer sistema digital. Estudamos como computadores representam dados com sistemas numéricos (binário, octal, hexadecimal), como a lógica booleana governa circuitos e decisões, e como a arquitetura de Von Neumann estrutura os computadores modernos.

Abordamos também conceitos de sistemas operacionais, gerência de processos, memória e introdução a redes de computadores — formando uma base sólida para compreender qualquer área da tecnologia.

Ementa resumida

✓ Sistemas de numeração (bin, oct, hex)
✓ Álgebra de Boole e portas lógicas
✓ Representação de dados (int, float, char)
✓ Arquitetura de Von Neumann
✓ CPU: ULA, UC e registradores
✓ Hierarquia de memória
✓ Sistemas operacionais e processos
◎ Introdução a redes de computadores
