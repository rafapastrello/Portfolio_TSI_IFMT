Controle de Fluxo

4 exercícios — if/else, switch e operador ternário

Exercícios práticos para fixar as estruturas de controle de fluxo em JavaScript. Clique em Executar em cada card para rodar o exercício no navegador.

03

Positivo, Negativo ou Zero

Estrutura if / else if / else

ex3.js
if (numero > 0) {
alert("Positivo");
} else if (numero < 0) {
alert("Negativo");
} else {
alert("Zero");
}

Dado um número digitado pelo usuário, identifica se é positivo, negativo ou zero usando if / else if / else.

05

Sistema de Notas

Estrutura if / else if / else

ex5.js
if (nota >= 7) {
alert("Aprovado");
} else if (nota >= 5) {
alert("Recuperação");
} else {
alert("Reprovado");
}

Classifica a nota do aluno em Aprovado (≥7), Recuperação (≥5) ou Reprovado (<5). A ordem das condições é essencial.

06

Nível de Habilidade

Estrutura switch / case

ex6.js
switch (nivel) {
case 1: alert("Iniciante"); break;
case 2: alert("Intermediário"); break;
case 3: alert("Avançado"); break;
default: alert("Inválido");
}

Recebe um número de 1 a 3 e retorna o nível correspondente. O switch compara valores exatos e o break impede a execução dos cases seguintes.

07

Maior ou Menor de Idade

Operador ternário ( ? : )

ex7.js
// condição ? se verdadeiro : se falso
let resultado =
idade >= 18
? "Maior de idade"
: "Menor de idade";

Verifica se a idade digitada é maior ou menor de 18 anos usando o operador ternário — um if/else compacto em uma única linha.
